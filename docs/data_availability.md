# Data availability

The BioSyn-Agent task release contains 22 biological design specifications,
fixed sequence and host contexts, component and reaction annotations, reference
designs, computational evaluation criteria and calibration mappings. Genetic
circuit resources derive from Cello and Eco1C1G1T1; bacterial sequence contexts
derive from E. coli accession U00096.3 and use EMOPEC activity predictions;
human 5′UTR resources derive from Sample et al. and GEO accessions GSM3130435,
GSM3130443 and GSM4084997; metabolic tasks use the iJO1366 reconstruction with
Rhea, UniProt and primary-literature reaction annotations.

The [dataset guide](../data/README.md) provides case-level files and usage
instructions. The [source table](../data/SOURCES.md) and
[machine-readable source records](../data/sources.json) identify the original
publications and access routes. Original scientific assets are retrieved from
their providers using the versioned download manifest.
